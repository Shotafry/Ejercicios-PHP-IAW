🌐 Ejercicios de PHP - IAW
Este repositorio contiene los trabajos prácticos realizados para la asignatura de Implantación de Aplicaciones Web. El objetivo es demostrar el uso de PHP básico y el control de versiones con Git.



Contenido del repositorio

001.php (Gestor de notas): Un programa que organiza una lista de estudiantes con sus notas. Calcula la media de cada alumno, dice quién ha aprobado o suspendido y muestra quién tiene la nota más alta.






002.php (Carrito de compras): Un simulador de tienda que suma los productos de una cesta. Calcula el precio total y aplica automáticamente descuentos del 5% o del 10% dependiendo de cuánto dinero se gaste.



003.php (Analizador de texto): Un script que lee una frase y analiza las palabras que contiene. Cuenta las palabras totales, ignora las que son muy cortas (menos de 3 letras) y busca cuál es la palabra que más veces se repite.




Requisitos del proyecto

Versionado: Todos los archivos se han gestionado mediante commits para llevar un seguimiento de los cambios.



GitHub: El código está alojado en este repositorio público para su entrega y revisión.


Formato: Los programas están diseñados para ejecutarse en un servidor con soporte PHP y mostrar los resultados de forma clara.
